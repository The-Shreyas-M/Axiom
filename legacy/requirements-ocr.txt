# OCR engine for scanned PDF pages (PaddleOCR on GPU).

# INSTALL NOTES (important):
# - This stack is tuned for Windows + NVIDIA GPU (RTX 3050 tested).

#     pip install -r requirements-ocr.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
# - paddlepaddle-gpu wheels are NOT on PyPI; Tsinghua carries them:
#     paddlepaddle-gpu 2.6.2 (this file) is a CUDA 11.8 build.
# - paddlepaddle-gpu on Windows does NOT bundle CUDA/cuDNN DLLs; the
#   nvidia-* packages below supply them. ocr.py adds them to PATH at runtime.
